Análise de Expressões Faciais com DeepFace no Google Colab

Este projeto realiza o reconhecimento automatizado de emoções a partir de imagens hospedadas na internet, utilizando a biblioteca **DeepFace** e processamento de imagem com **OpenCV** dentro do ambiente **Google Colab**.

O projeto utiliza como base teórica o estudo das 7 emoções universais de Paul Ekman, aplicando o modelo em fotografias autorais para validar a precisão do algoritmo.
